# Daily Engineering Task

Read control files, fetch/inspect branch/PR, run `PYTHONPATH=control-plane/src python3 -m pytest -q`, then ask: “What is the highest-value remaining blocker preventing PORTFOLIO COMPLETE — LOCAL-FIRST SCOPE?” Advance that P0 edge slice. Do not select polish/P2 work while blockers remain. Validate actual processes, ONNX execution, signatures, and network behavior before status changes. Update backlog/status, commit/push branch only, and report exact proof, simulated inputs and gaps.

As the project approaches completion, clean-room reproducibility becomes P0. Before declaring completion: tear down Project-owned infrastructure; verify teardown; bootstrap clean; smoke; run primary and failure/security demos; validate; clean again; bootstrap a second time; and record evidence. If either rebuild fails, fix it before cosmetic work.
