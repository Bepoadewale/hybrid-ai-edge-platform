# Hybrid AI Edge Platform

Foundation for operating local AI inference with policy-controlled cloud fallback, capability-aware model targeting, signed model-package contracts, desired-state reconciliation and staged fleet rollout.

## Honest status

This is an executable policy/domain foundation, not yet a running edge fleet. Device hardware values are simulated. ONNX Runtime, multi-process device agents, signed package cryptography, OTA rollout, cloud fixture, offline buffering and rollback execution remain future milestones.
