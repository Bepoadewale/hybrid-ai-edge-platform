# Definition of Done

- **Level 1:** routing/capability domain tests.
- **Level 2:** a signed tiny ONNX package runs through one independent local agent.
- **Level 3:** control plane and multiple agents perform registration, local inference, permitted cloud fallback, LOCAL_ONLY denial, desired-state update and bad-rollout rollback.
- **Level 4:** reproducible offline/tamper demos, CI, accurate hardware simulation labeling and no unsupported edge hardware claim.
